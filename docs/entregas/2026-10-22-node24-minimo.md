# Node 24 como versão mínima

- **Data**: 2026-10-22
- **Origem**: remover suporte a Node 22 e manter Node 24 LTS ou superior.

## Alterações

- `.nvmrc` aponta para a linha 24 LTS.
- `engines.node` exige `>=24` no pacote e na entrada raiz do lockfile.
- `.npmrc` mantém `engine-strict=true`, recusando instalações fora da faixa.
- CI valida Node 24 e 26; a cobertura é publicada pelo job Node 24.
- Auditoria, E2E e Pages usam `.nvmrc` e passam a executar no Node 24.
- README, onboarding, build, processo, instruções de agentes e modelo de
  README atualizados. As cópias locais das skills foram sincronizadas.
- ADR 0015 registra a mudança. Evidências e ADRs anteriores preservam o
  histórico, com referência à política atual nos ADRs substituídos.

## Validações locais

- Ambiente local: Node 24.18.0.
- `npm run sync:skills`: 11 skills sincronizadas.
- `npm run validate`: passou; 39 testes Vitest, 51 de scripts, checagens,
  tipos, build e smoke HTTP.
- Configurações e documentos operacionais não contêm recomendação de Node 22.
- A execução remota nas linhas 24 e 26 é registrada no CI do PR de integração.

## Como verificar

1. Execute `nvm install` e `nvm use` na raiz do projeto.
2. Confira `node --version`, `.nvmrc` e `package.json#engines`.
3. Execute `npm run validate`.
4. Confira os jobs Validate (Node 24) e Validate (Node 26) em Actions.
